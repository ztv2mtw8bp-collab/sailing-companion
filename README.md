# Sailing Companion

A companion app for sailors: plan trips, check conditions and keep a log of your time on the water.

> **Status:** Early stage. The project is just getting started.

## Planned features

- **Weather & wind**: forecasts, wind speed and direction, gusts
- **Tides & currents**: tide times and heights for nearby stations
- **Trip planning**: routes, waypoints and estimated passage times
- **Logbook**: record trips, distances, conditions and notes
- **Anchor alarm**: get alerted if the boat drifts from its anchored position
- **Safety**: checklists and quick access to emergency information

## Tech stack

- [Expo](https://expo.dev) (SDK 58) with React Native and TypeScript
- [Expo Router](https://docs.expo.dev/router/introduction/) for file-based navigation
- Runs on iOS and Android; the web build is mainly for quick previews

## Getting started

Requirements: Node.js 20 or newer, and the [Expo Go](https://expo.dev/go) app on your phone (or an iOS simulator / Android emulator).

```bash
npm install
npm start
```

Then scan the QR code with Expo Go (Android) or the Camera app (iOS). You can also press `i`, `a` or `w` in the terminal to open the iOS simulator, Android emulator or web browser.

### Useful scripts

| Command | What it does |
| --- | --- |
| `npm start` | Start the Expo dev server |
| `npm run ios` / `npm run android` / `npm run web` | Start and open on a specific platform |
| `npm run typecheck` | Type-check the project with TypeScript |
| `npm run lint` | Lint with ESLint (sets up the Expo config on first run) |

## Project structure

```
src/
  app/                 Screens and navigation (Expo Router: every file is a route)
    _layout.tsx        Root stack
    (tabs)/            Bottom tab bar
      index.tsx        Conditions: weather, wind and tides
      plan.tsx         Trip planning
      logbook.tsx      Logbook
      anchor.tsx       Anchor alarm
  components/          Shared UI components
  constants/           Theme colors and hooks
  types/               Shared TypeScript types (waypoints, routes, log entries)
  utils/               Helpers, e.g. distance in nautical miles and anchor radius checks
assets/                App icons and splash screen
```

Native `ios/` and `android/` folders are generated by Expo when needed and are not committed.
